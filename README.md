1)getElementById returns one element by ID, getElementsByClassName returns a live HTMLCollection by class, and querySelector / querySelectorAll use CSS selectors to return the first item or a NodeList of all items.

2)Using document.createElement(), then insert using method appendChild() or directly use innerHTML

3)Event bubbling is when an event starts at the target element and propagates upward through its parent elements.

4)Event delegation means attaching one event listener to a parent to handle events on its child elements using bubbling, improving performance and flexibility.

5)preventDefault() stops the browser’s default action, while stopPropagation() stops the event from bubbling up the DOM.
